## 本轮真实检查

原文 UTF-8 / CRLF / 图表字符布局；哈希与镜像；同文重复和显式修订；确认与内容分离；schema 校验；来源 bounds/字符边界；FTS 内容与字面中文检索；坏镜像/索引检测；迁移哈希；跨事件盘和证据；同事件多盘；事件家族分组；冻结不可重分；目标/未来/预测/反馈不进入事前输入；不可变盘对象；接口未实现状态；数据库规则到模型的真实传递；生成错误和事实错误分开；错误值不能渲染；最终文字门槛；空分析不成功；API 同入口、无维护写路由、输入限制；隐私不进入默认 trace；CLI 和备份。

测试中的 fixture_chart / fixture_role / fixture_symbol 都是中性工程占位，不是奇门符号，不可移入生产数据。注入模型只验证调用协议和校验，不是基础模型基线。

## 正式专业评估要求

仅从已提供文献建立带真实出处的事实测试。已覆盖确定性基础事实必须全通过；排盘需九宫逐项与来源对照，边界和各约定独立；来源不同的方法单独验收。

用神评估必须给完整问事背景及口径，条件不足测试只评估识别，不强迫断案。多盘按 chart_id 各自评分。综合断案需要真实非空证据和可评分标准，不存在的原书推理不得补造为标准答案。

发布评估集按完整 event_family 预先划分、冻结及版本化；跨书重复、多盘与衍生任务同组。人工审查叙述和标签的隐性反馈泄漏。目标答案与推理输入通过不同数据接口提供；完整书章节不得随意检索进预测上下文，避免同案例结局泄漏。公开学习模式与封闭评估输入权限分别设计。

## 指标分离与公平比较

至少分别报告：条件识别/补问、生成协议成功、断案完成、来源/证据正确、基础事实错、规则错、综合专业评分。generation_error、model_unavailable、blocked、verification_failed、final_verification_failed、structurally_verified 各自计数；拒答不等于答对。`evaluation.metrics.summarize` 当前不会为未评估项目生成准确率。

模型对照使用相同冻结任务、数据权限、上下文预算、生成设置与版本；比较原始、加盘、加检索、加条件、微调系统。报告分组样本量与不确定性、失败样本、专业评分人/方法和可复现配置。loss 或版本号不能代替性能。

现实预测另行预登记时间、可知信息、预测内容与截止期，记录完整随访和缺失，不挑选成功样本。作者历史叙述、历史复现与独立真实结果必须分开，不能宣称本轮任何现实预测能力。

失败处理：保存最小复现 → 判定资料/协议/算法/规则/模型/评分问题 → 不改原文和冻结答案来迎合程序 → 修复真实调用模块 → 运行相关回归 → 更新 STATUS 与版本差异。
