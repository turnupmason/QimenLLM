## 正式专业评估要求

## 指标分离与公平比较

至少分别报告：条件识别/补问、生成协议成功、断案完成、来源/证据正确、基础事实错、规则错、综合专业评分。generation_error、model_unavailable、blocked、verification_failed、final_verification_failed、structurally_verified 各自计数；拒答不等于答对。`evaluation.metrics.summarize` 当前不会为未评估项目生成准确率。

模型对照使用相同冻结任务、数据权限、上下文预算、生成设置与版本；比较原始、加盘、加检索、加条件、微调系统。报告分组样本量与不确定性、失败样本、专业评分人/方法和可复现配置。loss 或版本号不能代替性能。

现实预测另行预登记时间、可知信息、预测内容与截止期，记录完整随访和缺失，不挑选成功样本。作者历史叙述、历史复现与独立真实结果必须分开，不能宣称本轮任何现实预测能力。

失败处理：保存最小复现 → 判定资料/协议/算法/规则/模型/评分问题 → 不改原文和冻结答案来迎合程序 → 修复真实调用模块 → 运行相关回归 → 更新 STATUS 与版本差异。
