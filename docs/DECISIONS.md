# 技术决策记录

## D001 全新项目与授权边界

在 `/workspace/QimenLLM` 新建，不读取已有 Qimen，不导入旧案例/算法/v11 Excel/插件文献。研究技能只采纳来源、完整案例和评估纪律；其旧 schema、指定书系或非 LLM 预测架构不覆盖用户 QimenLLM 总指令。本轮无技能导致的审批暂停。

## D002 标准库优先

Phase 0 选择 Python >=3.11 + SQLite + unittest + WSGI，避免为了空库引入 CUDA 或框架。API 为研究接口，前端只预留接入边界，未建设或发布预测网站。未来根据需求换 HTTP 框架，统一服务不变。

## D003 权威原文字节、追加修订

SQLite BLOB + SHA-256 镜像，事务化索引/来源/版本，元数据冲突报错。触发器追加不可变表；字节哈希由程序审计。镜像先写可能留下孤立文件，优于事务失败时丢正文；孤立文件不自动成为知识。

## D004 状态拆分与延迟编译

来源确认与知识结构化、条件确认、规则编译、原盘解析/复算、模型专业评分各自独立；不因为程序不能复算否定原文。没有真实算法就返回 not_implemented，不填九宫和用神。

## D005 SQL 候选 + 条件决策

运行时查询参数化，候选语义相关不等于适用。缺值三态判断；多个合法方法不暗中唯一化。简单 DSL 可扩展，但不支持的专业条件先保持参考而非自由解释。

## D006 统一服务与诚实校验范围

CLI/API 共用 QimenService，临时 fixture 证明 DB/模型/校验接线。结构化复述校验只检事实与激活绑定，不宣称完整推断或自由中文验证；结构通过不计专业完成。以后要新增证据图和解释校验，不能绕过 service。

## D007 事件家族隔离

案例、多事件和多盘独立实体；同家族单一 split，冻结不改。初始训练投影保守只取明确事前对话，完整叙述与未知顺序不进入输入；续断输入权限与正式数据发布留后续有数据时实现。

## D008 私有设备与生产分工

当前云容器不是 Mac/家庭 GPU；家庭远程接入仅文档模板，没有扫描设备、VPN 配置或公网监听。模型可替换、不提前购买资源。未来设备上实测后锁定 CUDA 训练环境。

## D009 Git 与交付

本地初始化 main 并提交 Phase 0，不设置远程、不 push。代码/文档/测试进 Git；用户正文、SQLite、权重默认忽略，交付的空库作为可复现产物单独包含。ZIP 归档保留本地 Git 历史；打包 manifest 记录 commit 与文件哈希。当前云账户无法创建聊天指定的 `/codex/.../output` 路径（OS PermissionError），因此归档作为工程产物保存在项目 artifacts，不伪造附件链接。

## D010 初始 schema 定稿

在 Phase 0 尚无用户资料时调整 v1 并重建本轮新建空库。此操作不构成后续有数据时的迁移方案。定稿后任何 schema 修改必须新 migration、备份与回归；不能改已应用文件来掩盖迁移差异。
